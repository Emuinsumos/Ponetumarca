¿Por qué tener menú y pedidos digitales?

La idea no es solamente “tener una página”: es sumar una herramienta de venta y organización para el local.

Pedido más rápido

El cliente arma su pedido desde el celular, ve el total y lo envía sin depender de una conversación larga por WhatsApp.

Menú siempre actualizado

Precios, productos, fotos, categorías, combos y destacados se pueden modificar desde administración.

Más control

Los pedidos quedan registrados y permiten consultar estados, caja, ventas cobradas e histórico de productos.

WhatsApp integrado

Al confirmar el pedido, el sistema prepara automáticamente el mensaje con número, productos, total y datos necesarios.

Stock conectado

Los productos pueden asociarse a insumos para descontar cantidades automáticamente cuando entra un pedido.

Preguntas frecuentes

Un pequeño asistente responde preguntas configuradas por el negocio y puede derivar al cliente a WhatsApp.

El modelo de servicio

El primer mes es gratis para que el comercio pueda probar el sistema. A partir del segundo mes, el servicio tiene una suscripción de $25.000 mensuales, que mantiene la plataforma operativa y permite continuar utilizando sus herramientas.

Parte 1 · Experiencia del consumidor

Guía rápida para explicarle a cualquier cliente cómo hacer un pedido.

1. Explorar el menú

Desde la página se puede navegar por categorías, buscar productos por nombre y ver productos destacados.

2. Agregar productos

En cada producto aparece “Agregar al pedido”. El carrito muestra las cantidades y permite sumar o restar unidades.

3. Combos y promociones

Si hay combos cargados, aparecen en una sección destacada arriba del menú y se agregan al carrito como cualquier producto.

4. Elegir consumo

El cliente puede elegir entre Take away y Delivery. Para delivery solicita nombre, teléfono y dirección.

5. Elegir forma de pago

Se puede seleccionar efectivo, transferencia o QR cuando esas opciones están configuradas por el local.

6. Enviar pedido

Al tocar Enviar Pedido, se registra el pedido y se abre WhatsApp con el mensaje preparado para el negocio.

Seguí tu pedido

El cliente recibe un número de pedido. En la sección “Seguí tu pedido” ingresa ese número para consultar el estado.

Ingresar al administrador

Tocar el ícono de administración, completar usuario y contraseña y presionar Entrar. Al finalizar, usar Salir para cerrar la sesión de administración.

Pedidos · gestionar el flujo

Cada pedido muestra número, modalidad, hora, productos y total. El botón de estado permite avanzar el pedido paso a paso.

Enviar un aviso al cliente

Debajo del pedido hay un campo opcional para escribir un mensaje desde cocina, por ejemplo un aviso operativo. El cliente puede verlo en “Seguí tu pedido”.

Menú · mantener la carta

Para crear un producto: nombre, categoría, descripción, precio y foto. También se puede marcar como destacado para mostrarlo en el banner inicial.

Combos · vender promociones

Crear un combo con nombre, descripción, precio y foto. También puede consumir insumos del stock.

Stock · conectar insumos

Cargar cada insumo con nombre, unidad, cantidad actual y mínimo. Luego asociarlo a productos o combos indicando cuánto consume cada venta.

Categorías · ordenar el menú

Agregar una categoría nueva y asignarla a los productos. Una categoría no se puede borrar mientras tenga productos asociados.

Chatbot · preguntas frecuentes

Editar el saludo y crear preguntas con respuestas. El cliente toca una pregunta y recibe la respuesta configurada. También puede pasar a WhatsApp.

Configuración · datos del negocio

Actualizar logo, WhatsApp, Instagram, dirección, alias de transferencia y QR. Guardar la configuración para que los cambios se reflejen en la web.

Vista Cocina · modo pantalla

Pensada para una tablet, monitor o celular colocado en la cocina.

¿Cómo se abre?

Desde Pedidos, tocar “Abrir vista cocina”. Se abre una pantalla simplificada que muestra solamente los pedidos pendientes.

¿Qué puede hacer cocina?

Ver el orden de llegada, revisar productos y avanzar el estado con un botón grande. Según sea delivery o take away, el texto del siguiente paso se adapta.

Pagos y configuración

Las opciones de pago visibles dependen de lo que el administrador haya configurado.

Efectivo

El cliente puede indicar con cuánto abona. Esa información viaja dentro del pedido.

Transferencia

Se muestra el alias configurado y se solicita enviar comprobante junto con el número de pedido por WhatsApp.

QR

Se muestra el QR cargado por el administrador y se solicita enviar el comprobante por WhatsApp.

Importante: si WhatsApp no está configurado, el pedido no puede enviarse. Para transferencia debe existir un alias y para QR debe haberse cargado una imagen de QR.

Caja y control de ventas

Qué muestra Caja

  • Facturación del día seleccionado.
  • Cantidad de pedidos cobrados.
  • Desglose entre Take away y Delivery.
  • Total todavía por cobrar.
  • Lista de pedidos cobrados del día.
  • Historial de hasta los últimos días registrados.

Productos más vendidos

El módulo también calcula un ranking histórico de productos a partir de los pedidos que figuran como cobrados, mostrando cantidad vendida y total generado.

Buenas prácticas

Antes de abrir el local

Revisar precios, stock, WhatsApp, dirección y medios de pago. Verificar que las fotos y promociones estén actualizadas.

Durante el servicio

Mantener la vista Cocina abierta si se usa como pantalla de pedidos y avanzar cada pedido a medida que progresa.

Al cerrar

Revisar Caja, confirmar pedidos cobrados y consultar el total del día.

Cuando cambia la carta

Editar productos existentes antes de duplicarlos. Usar categorías para mantener una navegación simple.

Soporte y mantenimiento

La suscripción mensual incluye la continuidad del servicio digital y permite mantener la plataforma disponible para el comercio. Para cambios estructurales, nuevas funciones o modificaciones especiales, coordinar previamente con el responsable del servicio.

Seguridad: las credenciales de administración deben mantenerse privadas. No compartir este manual junto con usuario y contraseña en grupos públicos. Si se cambia la contraseña o la configuración técnica, actualizar la documentación interna.
